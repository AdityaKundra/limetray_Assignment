# LimeTray assignment

A task list built with React, Vite, and Tailwind. Tasks stay in the browser through `localStorage`.

You can add a task, mark it complete, delete it, and drag to reorder with dnd-kit. A filter switches between all, pending, and complete. The theme toggle stores light or dark mode in `localStorage`.

## Run it

```bash
npm install
npm run dev
```

Vite prints a local URL, usually `http://localhost:5173`.
